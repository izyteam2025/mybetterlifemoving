# Client input

First-hand facts from the client, collected every month. Google rewards pages that show real experience, and the monthly growth cycle may only state facts that trace to the client's files, so this folder is where new pages get their substance.

The questions and answers are managed in Notion, in the Client Input database inside the client's Pros Buddy Client Portal (`docs/growth/notion.json`). Each monthly run adds 3 to 5 questions there and assigns the project manager a task to ask them. The PM asks in the client's preferred channel, pastes each answer into its row, and sets it to Answered. The next run copies answered rows here into `YYYY-MM.md`, word for word, so the pages that use them have a source in the repo.

How the answers are used:
- A new page or post needs at least one answer (or another client file) as first-hand substance. Without one it is not written; the run refreshes existing pages instead.
- The reviewer checks that every claim about the client traces to a client file or to this folder.
- Photos the client sends go to `public/photos/` (WebP, alt text) and are named in the answer.

Never paste customer reviews here: reviews show only through the live widget.
